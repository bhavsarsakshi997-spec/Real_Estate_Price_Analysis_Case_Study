# 1. INTRODUCTION

Real estate is one of the important sectors of the economy. It includes residential and commercial properties such as apartments, houses, villas, and commercial buildings. Property prices are influenced by several factors, including location, property size, property type, age, furnishing status, and other facilities.

The **Real Estate Price Analysis** project focuses on analyzing property data from different locations in Ahmedabad, Gujarat, India, using Microsoft Excel.

This project uses a simulated dataset containing **250 property records**. The dataset includes important information such as Property ID, Property Type, Location, Area, Bedrooms, Bathrooms, Property Age, Parking Availability, Furnished Status, Sale Date, and Property Price.

Microsoft Excel is used to organize, clean, calculate, analyze, and visualize the property data. Different Excel features such as formulas, PivotTables, charts, statistical calculations, and regression analysis are applied to understand the dataset.

The project also includes an interactive-style dashboard that presents important performance indicators and visual summaries in an easy-to-understand format.

The main purpose of this study is to identify useful patterns in property prices, compare different locations, understand property-type distribution, and explore the relationship between property area and price.

**Note:** The dataset is simulated for educational and analytical purposes. It does not represent verified real estate transactions or actual market prices in Ahmedabad.

| Highest Property Price | Maximum property price |

| Total Locations | Number of unique locations |

## 10.3 KPI Formulas

Examples of Excel formulas:

**Total Properties**
`=COUNTA(tblProperties[Property_ID])`

**Total Sales Value**
`=SUM(tblProperties[Price])`

**Average Property Price**
`=AVERAGE(tblProperties[Price])`

**Highest Property Price**
`=MAX(tblProperties[Price])`

**Lowest Property Price**
`=MIN(tblProperties[Price])`

**Total Locations**
`=COUNTA(UNIQUE(tblProperties[Location]))`

**Average Price Per Sqft**
`=AVERAGE(tblProperties[Price]/tblProperties[Area_sqft])`
